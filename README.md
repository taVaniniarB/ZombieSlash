## Unreal 3인칭 액션 게임 (C++)

- **기간:** 2025.07.16 – 2025.09.16 (2개월)
- **개발:** 1인 프로젝트
- **기술:** Unreal Engine 5.4, C++

-----

### 개요

**다양한 무기와 아이템, 상호작용 콘텐츠를 구현한 액션 게임 프로토타입**

본 프로젝트는 **객체 지향적인 아키텍처**와 **데이터 기반의 확장 가능한 시스템**을 구축하는 데 중점을 두었습니다.

**주요 구현 시스템:**

  * **전투 시스템:** Enhanced Input 기반의 무기별 동적 입력 전환 및 상태 패턴을 활용한 총기 시스템 구현.
  * **아이템 시스템:** GameInstance Subsystem 기반의 **ItemManager**와 **LRU 캐시**를 활용한 비동기 아이템 데이터 로딩 및 관리 시스템.
  * **이펙트 시스템:** **Effect Manager 컴포넌트**를 통한 버프/디버프 이펙트의 중앙 집중식 관리.
  * **상호작용 시스템:** `IInteractable` **인터페이스**를 활용하여 재사용성과 확장성을 확보한 범용 상호작용 시스템.
  * **애니메이션/조작:** 근접 공격 중 이동 입력 시 **애니메이션 몽타주 종료 구간**을 활용하여 부자연스러운 모션 끊김 및 입력 지연 문제 해결.

### 기술

| 분야 | 핵심 내용 |
| :--- | :--- |
| **시스템 구조** | GameInstance Subsystem(`ItemManager`), Component(`EffectManager`, `InteractionComponent`)를 활용한 모듈화 및 책임 분리 |
| **객체 지향** | **상태 패턴** 기반 총기 상태 관리, **델리게이트 패턴**을 이용한 UI-로직 분리, `IInteractable` **인터페이스**를 통한 다형성 구현 |
| **최적화/성능** | **LRU 캐시**를 적용한 아이템 데이터 관리 및 비동기 로딩, **데이터 테이블** 기반의 메타데이터 조회로 불필요한 리소스 로드 방지 |
| **조작/애니메이션**| Enhanced Input System의 동적 컨텍스트 전환, 근접 공격 애니메이션의 \*\*`ExitSection`\*\*을 활용한 자연스러운 입력 반응성 확보 |
